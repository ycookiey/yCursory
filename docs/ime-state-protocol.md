# IME状態の受け取り（プロトコルv1）

IMEや外部ツールが、オン・オフとキャレットの位置をyCursoryに送れる。

送る側が入力を担当すると知らせたウィンドウを、担当ウィンドウと呼ぶ。

- 担当ウィンドウが前面にあり、オン・オフが知らされている間は、yCursoryは前面のアプリにIME状態を問い合わせず、知らせだけでカーソルの色を変える。
- 端末など、キャレットを取得できないアプリでも、知らせがあれば色が追従する。
- 担当ウィンドウが前面にない間と、担当開始からオン・オフが最初に知らされるまでの間は、yCursoryが自分で前面のアプリに問い合わせる。
- 送る側がいなければ、yCursoryは常に自分で前面のアプリに問い合わせる。

## 送り先

- yCursoryは、クラス名が`yCursory.ImeStateReceiver.v1`のメッセージ専用ウィンドウを作る。`FindWindowExW(HWND_MESSAGE, NULL, L"yCursory.ImeStateReceiver.v1", NULL)`で探し、`PostMessageW`で送る。`SendMessage`は使わない。送る側がyCursoryの処理を待たないようにするため。
- yCursoryが起動していない間は、受け口のウィンドウが見つからない。
- メッセージ番号は、`RegisterWindowMessageW`に次の名前を渡して得る。

| 名前 | wParam | lParam | 意味 |
|---|---|---|---|
| `yCursory.ImeState.v1.Focus` | ウィンドウのHWND | 1: 担当開始 / 0: 担当終了 | 指定したウィンドウの担当を始める、または終える。詳細は下の「Focusの動き」 |
| `yCursory.ImeState.v1.Open` | 1: オン / 0: オフ | 0 | 担当ウィンドウのIMEのオン・オフ。オンは日本語入力 |
| `yCursory.ImeState.v1.Caret` | `MAKELONG(left, top)` | `MAKELONG(right, bottom)` | キャレットの位置。変換中の文字列の位置でもよい。物理ピクセルで、各値は16ビット符号付き。wParamとlParamがどちらも`0x80008000`なら「位置なし」 |

HWNDと各値は32ビットに収まるので、32ビットのプロセスからも送れる。

### Focusの動き

HWNDには、担当するウィンドウの子ウィンドウを指定してもよい。yCursoryは`GetAncestor(hwnd, GA_ROOT)`で得た最上位のウィンドウ（以下、root）で比べる。

- 担当開始（lParamが1）: 指定したウィンドウのrootを担当ウィンドウにする。別のウィンドウを担当していた場合は置き換える。担当開始より前に`Open`で知らされていたオン・オフは、同じウィンドウへの担当開始でも捨てる。
- 担当開始で、HWNDが0または存在しないウィンドウの場合: 担当を始めず、今の担当ウィンドウがあれば担当を終える。
- 担当終了（lParamが0）で、HWNDのrootが担当ウィンドウと同じ場合: 担当を終える。
- 担当終了で、HWNDが0の場合: どのウィンドウの担当でも終える。
- 担当終了で、HWNDのrootが担当ウィンドウと別の場合: 何もしない。

### OpenとCaretの動き

- `Open`は、担当ウィンドウがない間は捨てる。担当ウィンドウが前面にあるときだけ、カーソルの色とキャレットインジケーターの色に反映する。
- `Caret`は、担当ウィンドウが前面にあるときだけ使う。yCursoryは`left`と`top`だけを使い、`right`と`bottom`は使わない。

## 送る側の決まり

- 担当開始を送った直後に、今のオン・オフを`Open`で送る。yCursoryは、担当開始の時点のオン・オフを知らない。
- 変換が終わったら、`Caret`の「位置なし」を送る。送らないと、最後の位置にキャレットインジケーターが残る。
- `Caret`は、変わるたびに全部送らなくてよい。まとめて最後の1件だけ送ればよい。
- 担当をやめるときは、担当終了を送る。
- 担当ウィンドウが前面でなくなると、yCursoryは担当を終える。担当ウィンドウが前面に戻ったら、改めて担当開始と`Open`を送る。

## yCursoryが知らせを使う条件

- 知らせを使うのは、前面のウィンドウのrootが担当ウィンドウと同じ間だけ。
- 前面の切り替えの通知をOSから受けたとき、前面のウィンドウのrootが担当ウィンドウと別なら、担当を終える。通知は遅れて届くことがあるため、通知が指すウィンドウではなく、通知を受けた時点の前面のウィンドウで比べる。担当ウィンドウが閉じられたと分かった時点でも、担当を終える。
- 担当を終えた後は、送る側が改めて担当開始を送るまで、yCursoryが自分で前面のアプリに問い合わせる。
- IME状態の確認が動いている間は、キャレットインジケーターの位置に自分で取得した値を使い、`Caret`の位置は使わない。確認は、キャレットを1秒続けて取得できないと止まる。`Caret`の位置を使うのは、確認を止めている間だけ。キャレットインジケーターが無効のときは、`Caret`の位置も使わない。
- 受け口は、誰からの知らせも受け付ける。サンドボックスのアプリの中のIMEなど、権限の低いプロセスからも届くように、`ChangeWindowMessageFilterEx`で許可している。偽の知らせで変わるのは、カーソルの色とキャレットインジケーターの表示だけ。
